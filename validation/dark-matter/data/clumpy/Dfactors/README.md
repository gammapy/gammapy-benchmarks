This folder contains all the 2D maps and profiles of the astrophysical factors for DM decay generated with CLUMPY for the analyzed dSphs. It is organized into the following subdirectories:

- `2Dmaps` is the repository for the 2D maps of astrophysical factors;
- `profile` is the repository for the astrophysical factor profiles as a function of the integration angle.

See inside each subdirectory for the detailed description of their content.
