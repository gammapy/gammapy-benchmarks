This folder contains all the DM density profiles generated with CLUMPY for the analyzed dSphs. It contains the following files:

- the DM density profiles for the CTAO-optimal dSphs computed with the Burkert functional form (file `dm_densityprofile_burkert.dat`);
- the DM density profiles for the other analyzed dSphs computed with the Burkert functional form (file `dm_densityprofile_burkert_others.dat`);
- the DM density profiles for the CTAO-optimal dSphs computed with the Einasto functional form (file `dm_densityprofile_einasto.dat`);
- the DM density profiles for the other analyzed dSphs computed with the Einasto functional form (file `dm_densityprofile_einasto_others.dat`).

The content of each file is organized as follows:

```
r dSph1 dSph1_LO dSph1_UP dSph2 dSph2_LO dSph2_UP ...
```

with `dSphN` the $N$-th dSph abbreviated name (e.g., CBe, DraI, etc.).
