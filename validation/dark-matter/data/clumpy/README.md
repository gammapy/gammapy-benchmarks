# Description of this folder

This folder is the official repository of all the astrophysical factors computed for the CTAO KSP on DM searches in dSphs. It is organized into three subdirectories:

- `DMdensity` is the repository for the DM density profiles of the analyzed dSphs;
- `Dfactors` is the repository for the astrophysical factors in the case of DM decay;
- `Jfactors` is the repository for the astrophysical factors in the case of DM annihilation.

See inside each subdirectory for the detailed description of their content.
